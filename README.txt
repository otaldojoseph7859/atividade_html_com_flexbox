ATIVIDADE PRÁTICA — RECRIAÇÃO DE UMA PÁGINA WEB COM FLEXBOX

Objetivo
Recriar visualmente a página-modelo utilizando HTML e CSS e aplicando os
conceitos de Flexbox estudados em aula.

Desafio do aluno
1. Observe a página-modelo.
2. Identifique as seções e a organização dos elementos.
3. Recrie a estrutura utilizando HTML semântico.
4. Utilize Flexbox para organizar cabeçalho, hero, cards e rodapé.
5. Tente aproximar espaçamentos, tamanhos e alinhamentos.
6. Faça a página funcionar também em telas menores.

Conceitos esperados
- display: flex
- flex-direction
- justify-content
- align-items
- gap
- flex
- flex-wrap
- width e max-width
- margin e padding
- imagens
- links e botões
- media queries

IMPORTANTE
O aluno deve construir sua própria solução. O código desta pasta é a
página-modelo/referência do professor e não deve ser simplesmente copiado.

SUGESTÃO
O professor pode fornecer aos alunos apenas uma captura de tela da página
e a pasta "images", deixando index.html e style.css para serem criados
pelos próprios alunos.
